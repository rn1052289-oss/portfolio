03 / Strengths

できることを、
根拠と一緒に。

Front-end

操作しやすい画面を実装する

レスポンシブ対応に加え、フォーカス制御、Escキー操作、aria属性、入力検証まで実装しています。

Design to Code

設計から画面までつなげる

情報設計とFigmaでのデザインから、HTML / CSS / JavaScript、WordPressテーマ化まで一人で進められます。

Authorization

権限とデータの境界を守る

Fortify / Sanctumによる認証と、Policyによる認可を実装。他のユーザーのデータが混ざらないことをテストで確認しています。

Consistency

同時に起きる処理でも、ずらさない

トランザクション、行ロック、unique制約を使い分け、予約や決済のデータを守ります。

Integration

外部サービスとつなぐ

Stripe、Google Calendar、Gemini、Google Booksと連携。通信に失敗したときの動きまで決めています。

Testing

うまくいかない場合を確かめる

PHPUnitで、権限のない操作、不正な入力、重複した通知などを重点的に確認しています。
